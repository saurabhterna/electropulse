# ⚡ ElectroPulse

Live India Assembly Election Results Dashboard 2026

Tracking results across 5 states — West Bengal, Tamil Nadu, Kerala, Assam & Puducherry (824 seats).

Built on [worldmonitor](https://github.com/koala73/worldmonitor) (MIT License).

## Features (WIP)
- Live seat tally per party
- Constituency-level map
- Swing analysis vs 2021
- Alliance tracker (NDA / INDIA bloc)
- Majority threshold tracker

## Stack
TypeScript, Next.js, Vercel Edge Functions

## Data Sources
- ECI (results.eci.gov.in)
- Lok Dhaba (TCPD, Ashoka University)
- Datameet GeoJSON shapefiles
